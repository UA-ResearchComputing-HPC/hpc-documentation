[https://hpcdocs.hpc.arizona.edu](https://hpcdocs.hpc.arizona.edu)

## Contributing

Documentation is written in Markdown and built with [Zensical](https://zensical.org/).

To work on the documentation locally:

```bash
git clone https://github.com/UA-ResearchComputing-HPC/hpc-documentation.git
cd hpc-documentation
```

Install the documentation dependencies (see the official Zensical documentation for information), then run the local development server: 

```bash
zensical serve
```
